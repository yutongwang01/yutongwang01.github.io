# yutongwang01.github.io

Personal academic website for Yutong Wang, built with [Eleventy](https://www.11ty.dev/) and deployed to GitHub Pages.

## Local development

```sh
npm install
npm start
```

## Production build

```sh
npm run build
```

The generated site is written to `_site/` and copied to the repository root for GitHub Pages. Editable content lives in `src/`; shared site information and publication records live in `src/_data/`. Do not edit generated root HTML files directly.
